Dokumentation

Installation

  1. Installer von Downloads laden, SHA-256 prüfen.
  2. Installer starten — keine Adminrechte nötig, Prüfsumme wird erneut verifiziert.
  3. Der Launcher legt %APPDATA%\VYRA für Profile, Config, Logs und Backups an.
  4. Deinstallation: Windows-Einstellungen → Apps → VYRA Client (Registry-Eintrag vorhanden).

Anmeldung (Microsoft)

  1. Im Launcher: Tab Accounts → eigene Azure-App-ID eintragen (siehe docs/ANMELDUNG.md im Repo).
  2. Anmelden → Code im Browser unter microsoft.com/link bestätigen.
  3. Der Launcher fragt nie nach deinem Passwort und speichert keines. Tokens liegen nur DPAPI-geschützt (CurrentUser).
  4. Der Launcher prüft die Minecraft-Berechtigung. Ohne Berechtigung: ehrliche Fehlermeldung. Ohne Login: ehrlicher Offline-Modus.

FPS-Optimierung

  • Tab Performance: Hardware-Stufe ablesen, Profil wählen (LOW → MAX FPS).
  • RAM: Empfehlung übernehmen — mehr als 6 GB schadet meist (GC-Pauses).
  • Performance-Set (Mods-Tab): installiert nur live-verifizierte 26.2-Mods (Sodium, Lithium, FerriteCore, ImmediatelyFast, Entity/ More Culling, Dynamic FPS, Sodium Extra, Reese's, ModMenu) — mit Bestätigung und Hash-Prüfung. ModernFix ist für 26.2 bewusst ausgenommen.
  • Benchmark starten misst Avg-FPS, 1%-Low, Frametimes, Spikes — nur echte Werte.
  • Vulkan ist experimentell: bei Grafik-Crashes automatisch zurück auf OpenGL.

Mods

  • Tab Mods: über Modrinth suchen (Loader fabric + deine MC-Version), Treffer wählen, Installieren (Lizenz wird gezeigt, Abhängigkeiten automatisch, Hash-geprüft).
  • Konfliktwarnungen ernst nehmen (z. B. Sodium + OptiFine).
  • Absturz? Mit Safe Mode im Profil starten — optionale Mods werden deaktiviert, nichts gelöscht.
  • Entfernen legt automatisch ein Backup unter backups/ an. Profile exportierbar.

Shader

  • Iris + Sodium über Mods-Tab installieren, Shaderpacks in den shaderpacks-Ordner der Instanz.
  • Shader brauchen das OpenGL-Backend. Bei Vulkan: erst Backend wechseln.

Fehlerbehebung

  • Tab Logs: Crash-Analyse mit Reparaturvorschlag lesen.
  • Dashboard: Prüfen verifiziert Client-JAR/Libraries/Natives per Hash, Reparieren lädt Fehlendes nach.
  • Kein Java? Java 21+ installieren (Launcher listet gefundene Runtimes).
  • Login scheitert? App-ID prüfen (36 Zeichen GUID), PC-Uhrzeit prüfen.

Updates

  • Der Launcher prüft beim Start GitHub Releases (Repo im Accounts-Tab eintragen).
  • Updates nur mit Zustimmung, Hash-geprüft, mit Rollback-Backup der alten EXE.

Datenschutz

Keine Telemetrie, keine Werbung, kein Account-Zwang außer Minecraft-Auth. Discord Presence nur per Opt-in. Alle Daten bleiben lokal unter %APPDATA%\VYRA, außer bei ausdrücklich gewähltem Export/Import.
