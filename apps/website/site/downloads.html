Installation

  1. Installer laden und SHA-256 prüfen.
  2. Installer starten (kein Admin nötig) — er prüft die Prüfsumme erneut und legt Desktop-/Startmenü-Verknüpfung an.
  3. Im Launcher: Java prüfen lassen, Profil wählen, PLAY drücken.
  4. Details: Dokumentation.

Hinweis: Es werden keine Minecraft-Spieldateien mitgeliefert. Der Launcher lädt sie beim ersten Start Hash-geprüft von offiziellen Mojang-Quellen. Ein Minecraft-Account mit Java-Berechtigung ist erforderlich.
