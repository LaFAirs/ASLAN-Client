# Security Policy

**Bitte keine Schwachstellen öffentlich posten, bevor sie behoben sind.**

* Melden per GitHub-Issue mit Label `security` (nur Beschreibung + Reproduktion,
  keine Exploits gegen fremde Systeme).
* Was wir garantieren: keine Telemetrie, keine Passwort-Speicherung, DPAPI für
  Tokens, Hash-Prüfung (SHA-1 Mojang, SHA-512 Modrinth, SHA-256 Releases),
  nur offizielle Download-Quellen (Mojang, Fabric-Meta/Maven, Modrinth-CDN).
* Unterstützte Version: jeweils das neueste `v*`-Release.
